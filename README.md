A daily learning log: one algorithm problem or one study note per day.

## 规则 / How it works

- 🧮 **算法题 Algorithms** → [`algorithms/`](algorithms/)：Python 解法，附题目描述（自己的话）、中文思路、复杂度和 `assert` 自测，直接 `python 文件名.py` 运行。
  Python solutions with the problem in my own words, approach, complexity, and asserts — run the file to self-test.
- 📝 **学习笔记 Notes** → [`notes/`](notes/)：读文档、看项目、学新工具时的笔记（Markdown）。
  Markdown notes from docs, projects, and new tools.
- 文件命名 File naming: `YYYY-MM-DD-主题`，例如 e.g. `2026-10-28-two-sum.py`

```text
daily-learning/
├── algorithms/   # 算法题 one problem per file
├── notes/        # 学习笔记 one note per file
└── README.md     # 目录与进度 index & progress
```
