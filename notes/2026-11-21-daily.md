# 2026-11-21 学习笔记：二分查找

今天学了二分查找：它只适用于有序数组，每次把查找区间对半砍掉一半，所以最多只要 log₂n 次比较就能找到目标，比从头到尾线性扫描快得多。

写法的关键是区间的定义要前后一致：用左闭右闭区间 `[left, right]` 时，循环条件是 `left <= right`，每次取 `mid = (left + right) // 2`，目标比 `mid` 大就让 `left = mid + 1`，比它小就让 `right = mid - 1`。

最容易写错的地方是边界：循环条件写成 `<` 会漏掉最后一个元素，更新边界时忘记 `+1` 或 `-1` 会导致死循环，记住“每次循环都要让区间真正缩小”就能避开这两个坑。

二分查找不只用来找数，还能用来找“第一个满足条件的元素”，比如在有序数组里找第一个大于等于目标值的位置，这类变体在面试和实际代码里都很常见。
