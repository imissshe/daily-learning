# 2026-11-17 学习笔记：git bisect

今天学习了 git bisect：当代码出现回归 bug、但不知道是哪次提交引入时，可以用它做二分查找来定位问题提交。先用 git bisect start 进入二分模式，再用 git bisect bad 标记当前提交有问题、git bisect good <已知好的提交> 划定范围，Git 会自动 checkout 中间提交让你逐个测试，每次回答 good 或 bad，直到定位到第一个坏提交。配合 git bisect run <测试脚本> 还能全自动跑完整个二分过程，非常省时间。关键是准备一个可靠的复现脚本或测试命令，否则二分结果不可信。
