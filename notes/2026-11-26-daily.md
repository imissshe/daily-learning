# 2026-11-26 学习笔记：Python sorted 与 key 参数

今天学了 Python 的 `sorted()`：它返回一个排好序的新列表，不会修改原对象，而列表的 `sort()` 方法则是原地排序、返回 `None`，两者别混淆。通过 `key` 参数可以指定排序依据，例如按字符串长度排序用 `key=len`，按字典某个字段排序用 `key=lambda d: d["score"]`，这样就不用手动写比较逻辑。`sorted()` 是稳定排序，`key` 相等的元素会保持原来的相对顺序，因此可以先按次要字段排一次、再按主要字段排一次，组合出多级排序的效果。需要降序时加上 `reverse=True` 即可；注意 `reverse` 是把比较结果反过来，而不是先升序再把列表倒过来，稳定性的含义略有不同。
