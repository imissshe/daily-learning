# 2026-11-14 每日学习笔记：Python 上下文管理器

今天学习了 Python 的上下文管理器（context manager）与 `with` 语句：任何实现了 `__enter__` 和 `__exit__` 的对象都可以用 `with` 管理，代码块结束时会自动释放资源，即使中间抛出异常也不例外。

最常见的例子是打开文件：`with open('data.txt') as f:`，读完后文件会自动关闭，不用再手写 `f.close()`，也不怕异常导致文件句柄泄漏。除了文件，锁、数据库连接、临时目录切换都适合用这种方式管理。

自己写上下文管理器也不难：用 `contextlib.contextmanager` 装饰一个生成器函数，`yield` 之前写进入逻辑、`yield` 之后写清理逻辑，几行代码就能得到一个可复用的 `with` 工具。以后凡是“用完必须还回去”的资源，都优先考虑包成上下文管理器。
