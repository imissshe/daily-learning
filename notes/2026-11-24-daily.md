# Daily Learning — 2026-11-24

今天学了 `git stash`：它可以把工作区和暂存区还没提交的改动临时“藏”起来，让工作区回到干净状态，方便先切换分支去处理紧急任务，之后再用 `git stash pop` 把改动恢复回来。`git stash push -m "描述"` 可以给每一次暂存加备注，`git stash list` 能查看所有暂存记录，`git stash apply stash@{1}` 则可以恢复指定的某一条而不删除它。需要注意的是，默认情况下 stash 不会包含未被追踪的新文件，需要加上 `-u` 参数才会一并暂存；如果改动里混进了不想提交的调试代码，`git stash push -p` 还能交互式地逐块挑选要暂存的部分。
