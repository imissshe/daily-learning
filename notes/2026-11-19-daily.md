# 2026-11-19 学习笔记：Python dataclasses

今天学习了 Python 的 dataclasses 模块：给类加上 @dataclass 装饰器后，__init__、__repr__、__eq__ 这些样板方法会自动生成，写数据容器类时不用再手写一堆重复代码。字段用 field(default_factory=list) 可以避免可变默认值被所有实例共享这个经典坑，frozen=True 还能得到不可变的数据类，适合当配置或值对象。用 dataclass 写出来的类既简洁又自带可读的打印输出，比普通类或 namedtuple 更灵活。之后遇到只存数据、不带复杂行为的类，可以优先用 dataclass 而不是手写 __init__。
