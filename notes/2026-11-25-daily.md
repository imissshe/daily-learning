# 2026-11-25 学习笔记：Python 异常处理

今天学了 Python 的异常处理：`try` 里放可能出错的代码，`except` 捕获指定类型的异常并处理，这样程序不会因为一次错误就直接崩掉。`else` 分支只在没有异常时执行，适合放依赖成功结果的后续逻辑；`finally` 则无论是否出错都会执行，常用来关闭文件、释放锁等清理工作。捕获异常时应尽量写具体类型（如 `ValueError`、`FileNotFoundError`），避免用裸 `except:` 把真正的 bug 也吞掉。需要把异常继续往上抛时直接用 `raise`，或用 `raise ... from e` 保留原始异常链，方便排查。
