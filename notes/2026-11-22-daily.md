# 2026-11-22 学习笔记：Python 推导式

今天学了 Python 的推导式：列表推导式 `[x*x for x in range(10) if x % 2 == 0]` 一行就能完成"循环 + 判断 + 收集"三件事，比先建空列表再 append 的写法简洁得多。

字典推导式 `{k: v for k, v in items}` 和集合推导式 `{x for x in ...}` 也是同样的思路，适合从已有数据快速构造新的映射或去重集合。

需要注意两点：推导式里不要嵌套太深，超过两层循环可读性会急剧下降；大数据量时优先用生成器表达式 `(x for x in ...)`，它惰性求值、不一次性占满内存。以后写数据转换的小逻辑，可以先想想能不能用一行推导式代替显式循环。
