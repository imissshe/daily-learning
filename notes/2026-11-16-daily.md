# 每日学习 2026-11-16

今天学习了 Python 的 `functools.lru_cache`：它是一个装饰器，能把函数的返回值按参数缓存起来，重复调用时直接命中缓存，适合计算昂贵、无副作用的纯函数。

`maxsize` 控制缓存的条目数上限，设为 `None` 表示不设上限；缓存满了之后会按最近最少使用（LRU）淘汰旧条目。

带上 `typed=True` 可以区分 `1` 和 `1.0` 这种值相等但类型不同的参数，避免缓存串味。

要注意它只适用于参数可哈希的函数，传入列表或字典会直接报错；需要手动清理缓存时调用 `cache_clear()`，想看命中率则用 `cache_info()`。
